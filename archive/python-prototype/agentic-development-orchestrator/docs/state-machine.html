Agentic Development Orchestrator

Lifecycle state machine: source-driven planning, isolated execution, independent verification, bounded rework, integration and gated delivery.

Preparation / execution Approval / verification gate Passed state Rework / blocked

State definitions

PLANNED → READY

Task is defined, dependencies pass, assigned agents exist, and isolation is available.

RUNNING → REVIEW

Implementation attempt completed and artifacts/diff are available for independent inspection.

REVIEW → PASS / REWORK

PASS requires all mandatory criteria and evidence. FAIL routes to bounded rework.

PASS → INTEGRATED

Verified task changes are integrated and integration checks pass.

MILESTONE REVIEW

All tasks, traceability, regression and milestone evaluations are checked together.

BLOCKED

Unresolved dependency, permission, review, retry or approval issue requires intervention.

Important invariants

  • Implementer and reviewer must be independent.
  • Parallel tasks cannot have overlapping write scopes.
  • Failed mandatory checks cannot transition to PASS.
  • Task PASS does not imply milestone PASS.
  • State records must be reconciled with actual Git state before resume.
  • Worktree cleanup occurs only after verified integration and a clean worktree.
